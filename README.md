## Pendente

- Adicionar o link da Rua Digital na Play Store quando estiver disponível.
- Trocar `SEUEMAIL@DOMINIO.COM` em `index.html` pelo e-mail que receberá os pedidos de novos aplicativos.

## GitHub Pages

A página principal é `index.html` na raiz da branch `main`.

Para publicar via GitHub Pages, abra **Settings → Pages**, selecione **Deploy from a branch**, escolha **main** e **/(root)** e salve.

Se o repositório permanecer privado, a disponibilidade do Pages depende do plano/configuração da conta.
